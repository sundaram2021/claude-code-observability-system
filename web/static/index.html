Connecting Claude Code CLI to this Observability Platform

Claude Code includes native OpenTelemetry (OTel) support. Configure your terminal:

export OTEL_EXPORTER_OTLP_ENDPOINT="http://localhost:3000/v1/traces"
export OTEL_EXPORTER_OTLP_PROTOCOL="http/json"
claude "Refactor the auth handler and run tests"

Using with Langfuse SDK or Claude Hooks

Stream JSON events to POST /api/v1/events or use Langfuse batch ingestion at POST /api/public/ingestion.
